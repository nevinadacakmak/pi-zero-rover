# Pi Zero Rover

## Project Goal

Build a battery-powered rover from scratch, chassis, electronics, and all software written in C. Controllable remotely via live camera feed, exposed over the internet through self-hosting.

Learning goals: embedded software, Linux, GPIO, autonomous systems, computer vision, camera.
